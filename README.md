# トランプで学ぶ！並び替え

#　概要

「ソート（Sort）」とは、バラバラに並んだデータ（トランプのカードなど）を、特定のルール（数字が小さい順、大きい順など）に従って綺麗に並べ替える処理のことです。コンピュータの世界では、データを効率よく探す（検索する）ための大前提となる非常に重要な技術です。そのための教材として視覚的に学べるように作成しました．

#構成

以下のような構成で教材を作成しています．
1. ソートの概要を知る
   内容: 「なぜコンピュータはデータを並べ替える必要があるのか」を、日常の例えを交えて分かりやすく解説します。ソートの基本概念をまずはインプットします。
2. ソートをアニメーションで見る
   内容: 代表的なソートアルゴリズムが、実際にどのようにカードを動かして整列していくのかをアニメーションで視覚的に確認できます。動きを見ることで、処理の仕組みが直感的に腹に落ちます。
3. 実際に手で動かす
   内容: 「最大2枚までしかトランプを表にできない」という制限（あるいは条件）の中で、どのように効率よくソートを再現・実行すればよいかを考えながら操作します。
4. クイズに答える
   内容: ここまでで学んだ内容がしっかり身についているかを確認できる、3択の確認クイズが用意されていま　す。理解度をテストして定着を図ることができます。
